# Python Study Manager

A terminal-based study management system built with Python.

## Project Status

Version 10 completed.

This project is currently considered complete as a terminal-based Python application. Future improvements may include a web version using Flask and SQLite.

## Features

- Task management
- Study session tracking
- Project tracking
- JSON data persistence
- Search and filters
- Weekly and monthly reports
- Project progress reports
- Dashboard overview
