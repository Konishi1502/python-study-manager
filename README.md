# Python Study Manager

A terminal-based study management system built with Python.

## Features

- Task management
- Study session tracking
- Project tracking
- JSON data persistence
- Search and filters
- Weekly and monthly reports
- Project progress reports
- Dashboard overview

## Technologies

- Python
- JSON
- Git
- GitHub

## Project structure

- main.py
- tasks.py
- sessions.py
- projects.py
- reports.py
- filters.py
- storage.py
- utils.py
